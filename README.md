# 🍲 Azzam Restaurant — Website

موقع مطعم **عزّام** في برلين — نيو كولن (Sonnenallee 54, 12045 Berlin).
موقع ثابت بالكامل مبني بـ **HTML + CSS + JavaScript** فقط (بدون خادم أو قاعدة بيانات).

## ✨ المزايا
- 🌐 **لغتان**: العربية (RTL) والإنجليزية (LTR) مع حفظ اختيارك.
- 🗺️ **خريطة Google** مضمّنة (بدون مفتاح API — `output=embed`).
- 🛒 **سلة تسوق** كاملة: إضافة/إزالة/كميات مع حفظها في المتصفح.
- 💬 **طلب عبر واتساب**: نموذج يطلب (الاسم الكامل، الهاتف، المدينة، المنطقة، العنوان بالتفاصيل، ملاحظات اختياري) ويبني رسالة كاملة تفتح في واتساب.
- 🥡 خيار **توصيل أو استلام من المطعم** يغيّر حقول النموذج تلقائياً.
- 🌱 شارات **نباتي / نباتي صرف / لحم** على كل صنف + فلتر «نباتي صرف».
- 🔍 بحث فوري في القائمة.
- 🎨 تصميم داكن فاخر (ذهبي/زيتوني) متجاوب مع الجوال.
- 🔘 **زر واتساب عائم** يرافقك أثناء التصفح.

## 📄 بنية الملفات
```
index.html                 # الصفحة الرئيسية (الواجهة)
assets/
  css/style.css            # التصميم كاملاً
  js/config.js             # ⚙️ الإعدادات (الرقم، العنوان، الروابط…) — عدّل هنا
  js/i18n.js               # نصوص الواجهة عربي/إنجليزي
  js/menu-data.js          # بيانات القائمة (الأصناف والأسعار)
  js/app.js                # منطق الموقع (لغة، سلة، واتساب، خريطة)
  img/                     # الصور
```

## ⚙️ التعديل السريع (مهم)
كل شيء قابل للتعديل من **`assets/js/config.js`**:
- **رقم واتساب**: `phone.whatsapp` (بالصيغة الدولية بدون `+`، مثال `493060977541`).
- **الهاتف المعروض**: `phone.display` / `phone.tel`.
- **العنوان**: `location.*`.
- **انستغرام**: `social.instagram`.
- **خريطة Google**: `maps.embed` / `maps.directions` / `maps.place`.

### تغيير الأسعار أو الأصناف
عدّل **`assets/js/menu-data.js`** — كل صنف:
```js
{ id: "t-kafta", cat: "teller", de: "Kafta", ar: "كفتة", price: 6.5, diet: "meat" }
```
> `diet`: `"vegan"` 🌱 / `"veg"` 🥗 / `"meat"` 🥩

### صور الأطباق
ضع صورة كل طبق في **`assets/img/dishes/`** باسم **مطابق لـ `id`** (مثال: `t-kafta.jpg`).
الموقع يعرضها تلقائياً، وإن لم توجد صورة لطبق بعد يعرض صورة قسمه كبديل (لا تظهر صور مكسورة أبداً).
عند استبدالها بصور أطباقك الحقيقية يكفي حفظها بنفس الاسم.

## 🖥️ التشغيل محلياً
```
cd azzam_restaurant
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`

## 🔒 ملاحظة أمنية
لا توجد أسرار أو مفاتيح API أو قاعدة بيانات في هذا الموقع — الطلب يُبنى في المتصفح ويفتح في تطبيق **واتساب** مباشرة. لذلك لا تخزّن في `config.js` أي شيء حساس.

## ✍️ ملاحظة ترخيص خط «ثمانية»
خط **ثمانية (Thmanyah)** مملوك لشركة ثمانية وترخيصه المعلن للاستخدام **الشخصي فقط**. تم ربطه عبر CDN (`@dawod/thmanyah-font-web`) في هذا الموقع للعرض، مع **خط بديل (Cairo)** في حال تعذّر تحميله. قبل استخدام الموقع لأغراض تجارية، ننصح بالحصول على ترخيص استخدام من [font.thmanyah.com/licenses](https://font.thmanyah.com/licenses) أو التواصل مع ثمانية (Ask@thmanyah.com)، أو استبداله بخط مفتوح (Cairo / Almarai) من سطر `style.css` إذا رغبت.

## 📸 حقوق الصور
الصور المستخدمة مولّدة خصيصاً لهذا المشروع، ويمكن استبدالها بصور أطباقك الحقيقية بوضعها في `assets/img/`.
