# Azzam Restaurant — Website

موقع مطعم **عزّام** في برلين — نيو كولن (Sonnenallee 54, 12045 Berlin).
موقع ثابت بالكامل مبني بـ **HTML + CSS + JavaScript** فقط (بدون خادم أو قاعدة بيانات).

## المزايا
- **ثلاث لغات** من قائمة منسدلة في الهيدر: العربية (RTL)، English، Deutsch (LTR) — مع حفظ الاختيار في المتصفح، وتغيّر عنوان الصفحة ووصفها مع اللغة.
- **خريطة Google** مضمّنة (بدون مفتاح API — `output=embed`).
- **سلة تسوق** كاملة: إضافة/إزالة/كميات مع حفظها في المتصفح.
- **طلب عبر واتساب**: نموذج يطلب (الاسم الكامل، الهاتف، المدينة، المنطقة، العنوان بالتفاصيل، ملاحظات اختياري) ويبني رسالة كاملة تفتح في واتساب.
- خيار **توصيل أو استلام من المطعم** يغيّر حقول النموذج تلقائياً.
- شارات **نباتي / نباتي صرف / لحم** على كل صنف + فلتر «نباتي صرف» + بحث فوري.
- **أيقونات SVG** موحّدة لكل عناصر الموقع (بدون أي إيموجي) — تعبّر عن كل قسم وعنصر: هاتف، ساعة، موقع، دراجة للتوصيل، واجهة متجر للاستلام…
- حالة **مفتوح/مغلق الآن** محسوبة على توقيت برلين.
- تصميم داكن فاخر (ذهبي/زيتوني) متجاوب مع الجوال، ومحتوى الفوتر في الوسط على الشاشات الصغيرة.
- **زر واتساب عائم** يرافقك أثناء التصفح.

## بنية الملفات
```
index.html                 # الصفحة الرئيسية (الواجهة) + مكتبة أيقونات SVG (sprite) في أعلى الـ body
assets/
  css/style.css            # التصميم كاملاً
  js/config.js             # الإعدادات (الرقم، العنوان، الروابط…) — عدّل هنا
  js/i18n.js               # نصوص الواجهة عربي/إنجليزي/ألماني
  js/menu-data.js          # بيانات القائمة (الأصناف والأسعار)
  js/app.js                # منطق الموقع (لغة، سلة، واتساب، خريطة)
  img/                     # الصور + favicon.svg
```

## التعديل السريع (مهم)
كل شيء قابل للتعديل من **`assets/js/config.js`**:
- **رقم واتساب**: `phone.whatsapp` (بالصيغة الدولية بدون `+`، مثال `493060977541`).
- **الهاتف المعروض**: `phone.display` / `phone.tel` — يُعرض تلقائياً في كل مكان (الشريط، الموقع، الفوتر) وبالاتجاه الصحيح حتى داخل النص العربي.
- **العنوان**: `location.*`.
- **ساعات العمل**: `hours.open` / `hours.close` (تُستخدم لحساب «مفتوح الآن»).
- **انستغرام**: `social.instagram`.
- **خريطة Google**: `maps.embed` / `maps.directions` / `maps.place`.

### تغيير الأسعار أو الأصناف
عدّل **`assets/js/menu-data.js`** — كل صنف:
```js
{ id: "t-kafta", cat: "teller", de: "Kafta", en: "Kafta", ar: "كفتة", price: 6.5, diet: "meat" }
```
> `diet`: `"vegan"` (نباتي صرف) / `"veg"` (نباتي) / `"meat"` (لحم) — لكل نوع أيقونة SVG خاصة.

### صور الأطباق
ضع صورة كل طبق في **`assets/img/dishes/`** باسم **مطابق لـ `id`** (مثال: `t-kafta.jpg`).
الموقع يعرضها تلقائياً، وإن لم توجد صورة لطبق بعد يعرض صورة قسمه كبديل (لا تظهر صور مكسورة أبداً).

### الأيقونات
كل الأيقونات رموز SVG داخل `index.html` (`<symbol id="i-...">`). للاستخدام في HTML:
```html
<svg class="ico"><use href="#i-phone"></use></svg>
```
ومن JavaScript: `icon("phone")`. لإضافة أيقونة جديدة أضِف `<symbol>` جديداً إلى المكتبة نفسها.

### النصوص والترجمة
- نصوص الواجهة في `assets/js/i18n.js` (مفاتيح متطابقة للغات الثلاث). صيغ الجمع (مثل «9 أصناف») عبر `Intl.PluralRules`.
- أرقام الهاتف والأسعار والعناوين اللاتينية توضع داخل عناصر `dir="ltr"` أو بالصنف `.ltr` كي لا ينقلب ترتيبها في الواجهة العربية.
- لا تستخدم `letter-spacing` على نص عربي — يفصل الحروف المتصلة (الأنماط الحالية تعطّله تلقائياً في العربية).

## التشغيل محلياً


## ملاحظة أمنية
لا توجد أسرار أو مفاتيح API أو قاعدة بيانات في هذا الموقع — الطلب يُبنى في المتصفح ويفتح في تطبيق **واتساب** مباشرة. لذلك لا تخزّن في `config.js` أي شيء حساس.

## ملاحظة ترخيص خط «ثمانية»
خط **ثمانية (Thmanyah)** مملوك لشركة ثمانية وترخيصه المعلن للاستخدام **الشخصي فقط**. تم ربطه عبر CDN (`@dawod/thmanyah-font-web`) في هذا الموقع للعرض، مع **خط بديل (Cairo)** في حال تعذّر تحميله. قبل استخدام الموقع لأغراض تجارية، ننصح بالحصول على ترخيص استخدام من [font.thmanyah.com/licenses](https://font.thmanyah.com/licenses) أو التواصل مع ثمانية (Ask@thmanyah.com)، أو استبداله بخط مفتوح (Cairo / Almarai) من سطر `style.css` إذا رغبت.

## حقوق الصور
الصور المستخدمة مولّدة خصيصاً لهذا المشروع، ويمكن استبدالها بصور أطباقك الحقيقية بوضعها في `assets/img/`.
